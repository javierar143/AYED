# AYED - Algoritmos y Estructuras de Datos

Repositorio de ejercicios en Java basados en el programa de la materia.

## Contenido

- Clases, herencia y tipos genéricos  
- Pilas, colas y listas  
- Árboles binarios y generales  
- Interfaces y estructuras ordenadas (Comparable, ABB)  
- Heaps y colas de prioridad (HeapSort)  
- Análisis de algoritmos (tiempo de ejecución, Big-O)  
- Grafos (representación, DFS, BFS)  
- Ordenamiento topológico  
- Caminos mínimos (Dijkstra, Floyd)  
- Árbol generador mínimo (Prim, Kruskal)

## Lenguaje

Java
